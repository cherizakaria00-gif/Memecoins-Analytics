# Memecoins Analytics (Pulse)

Solana memecoin scanner and trading assistant: live scanner (pump.fun + DexScreener), quality filter,
graded signals with entry/stop/target plans, realistic paper trading, non-custodial live trading
(you sign every swap in your own wallet), alerts, subscriptions (card via Stripe, or crypto with manual
approval) and an admin dashboard.

> Not financial advice. Memecoins are extremely risky — you can lose everything you invest.

## Run locally

```bash
cp .env.example .env   # fill in your own values; never commit .env
npm install
npm start              # http://127.0.0.1:4173
npm test
```
